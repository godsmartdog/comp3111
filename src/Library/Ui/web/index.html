COMP3111 E-Library System

Welcome to our E-Library System. This platform supports Student, Staff, Author, and Librarian workflows in one place. You can register and sign in by role, search and borrow approved books, submit drafts and publications as an author, and review pending submissions as a librarian.

The system is built with role-based access, secure password policy, recommendation support, and complete submission review flow.

Database note: this demo saves runtime data to data/library-db.ser. First startup creates a new database; later startups load it. Delete src/data/library-db.ser to reset back to seeded demo data.

Crash recovery demo: logged-in pages save your last screen and unsaved form fields. Use the Crash Test button to simulate an abrupt crash, then restart the app to restore.
