# 图书馆管理系统操作说明

## 1. 文档说明
本说明面向当前项目的 Web UI 版本（HTML/CSS/JavaScript），内容基于现有实现编写，适用于本地运行后的实际操作。

系统目前提供三个主要界面标签页：
- Student / Staff：学生与教职员借书入口
- Author：作者投稿入口
- Librarian：馆员审核入口

## 2. 启动系统
### 2.1 启动前准备
请确认本机已经具备以下环境：
- Java 已安装
- JavaFX SDK 已安装
- 项目中的运行脚本可正常执行

### 2.2 推荐启动方式
在 PowerShell 中进入以下目录：

```powershell
Set-Location "C:\Users\lam09\Downloads\comp3111-main\comp3111-main\src\Library"
```

如果系统阻止脚本执行，可先运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

启动 Web UI：

```powershell
.\Run-Library.ps1 -Web
```

如果只想快速测试服务能否启动：

```powershell
.\Run-Library.ps1 -SmokeTest
```

注意：
- `-SmokeTest` 只用于启动检查，程序会自动关闭
- 要正常长期使用界面，请使用 `-Web`
- 为兼容旧脚本，`-JavaFX` 仍可用，但会启动同一个 Web UI

## 3. 系统启动后的默认演示数据
通过 JavaFX 启动器进入系统后，系统会自动创建以下演示账号：
- 学生账号：`student1`
- 作者账号：`author1`
- 馆员账号：`librarian1`
- 统一密码：`Password1!`

系统还会自动准备以下演示数据：
- 1 本可借阅图书
- 1 本已被借出的图书
- 1 条待馆员审核的投稿记录

因此，即使你不手动注册新账号，也可以先用演示账号体验流程。

## 4. 主界面结构说明
界面顶部显示系统标题，中央为三个不可关闭的标签页：
- Student / Staff
- Author
- Librarian

每个标签页内部大致分为左右两栏：
- 左侧通常是注册、登录、状态信息
- 右侧通常是核心业务操作区

## 5. Student / Staff 标签页操作说明
### 5.1 功能概览
该页面用于：
- 注册学生或教职员账号
- 登录学生或教职员账号
- 搜索图书
- 查看图书摘要
- 借阅图书
- 查看热门推荐
- 查看当前借阅记录

### 5.2 注册学生或教职员账号
在左侧的 `Student/Staff Registration` 区域填写：
- Username：用户名
- Full Name：姓名
- Password：密码
- Role：选择 `STUDENT` 或 `STAFF`

然后点击 `Register`。

#### 密码规则
密码必须满足以下条件：
- 长度 8 到 64 位
- 至少包含 1 个大写字母
- 至少包含 1 个小写字母
- 至少包含 1 个数字
- 至少包含 1 个特殊字符
- 不能包含空格

示例密码：
- `Password1!`

### 5.3 登录学生或教职员账号
在左侧的 `Student/Staff Login` 区域填写：
- Username
- Password
- Role：必须与注册角色一致

点击 `Login` 后：
- 页面状态会更新为已登录用户
- 借阅功能会被启用
- 当前借阅记录会刷新

### 5.4 搜索与查看图书
右侧上方有图书搜索区域：
- 在搜索框中输入书名或作者名关键词
- 点击 `Search` 进行筛选
- 点击 `Show All` 查看全部已审批图书

图书表格包含以下信息：
- Book ID
- Title
- Author
- Publish Date
- Availability

#### 颜色说明
图书标题会显示颜色：
- 黑色：可借阅
- 红色：当前不可借阅

点击任意图书后，下方 `Selected Book Summary` 区域会显示该书摘要。

### 5.5 借阅图书
借阅前必须满足以下条件：
- 已登录学生或教职员账号
- 已选中一本图书
- 图书状态为可借阅

借阅步骤如下：
1. 在图书表中选中一本可借阅图书
2. 在 `Borrow Days` 里选择借阅天数
3. 点击 `Borrow Selected Book`
4. 在弹出的确认窗口中核对信息并确认

#### 借阅天数规则
当前系统规则为：
- 最少 1 天
- 最多 14 天
- 默认值为 14 天

#### 借阅成功后结果
借阅成功后：
- 系统弹出成功提示
- 图书可借状态会立即更新
- 推荐列表会刷新
- `My Active Borrows` 列表会刷新

### 5.6 推荐与当前借阅
#### Popular Recommendations
显示当前热门图书推荐。

#### My Active Borrows
显示当前登录用户尚未归还的记录。
当前显示格式为：
- `BookID (due 日期)`

注意：目前该区域显示的是图书 ID 和到期日，不是书名。

## 6. Author 标签页操作说明
### 6.1 功能概览
作者页面用于：
- 注册作者账号
- 登录作者账号
- 自动保存草稿
- 加载草稿
- 预览投稿内容
- 正式提交书稿给馆员审核

### 6.2 注册作者账号
在左侧 `Author Registration` 区域填写：
- Username
- Full Name
- Password
- Bio

点击 `Register Author` 完成注册。

### 6.3 登录作者账号
在左侧 `Author Login` 区域填写：
- Username
- Password

点击 `Login Author` 后，页面顶部状态会更新为当前作者。

### 6.4 查看与加载草稿
左侧中下部为 `Saved Drafts` 草稿列表。

操作方式：
1. 先登录作者账号
2. 如果已有保存草稿，会显示在列表中
3. 单击某条草稿
4. 点击 `Load Selected Draft`
5. 草稿内容会自动填入右侧投稿表单

### 6.5 填写投稿表单
右侧 `Author Submission` 区域主要字段如下：
- Title：书名
- Genres：分类，多个分类用英文逗号分隔
- File Path：文件路径
- Description：简介

#### 支持的分类
当前系统支持以下分类：
- Biography
- Education
- Fantasy
- Fiction
- History
- Mystery
- Non-Fiction
- Romance
- Science
- Technology

填写时必须使用这些支持的分类名称。

### 6.6 自动保存草稿
填写部分内容后，点击 `Auto-Save Draft`：
- 系统会保存当前表单内容
- 保存后草稿列表会刷新
- 同一作者若使用相同标题，会更新原草稿

### 6.7 预览投稿
点击 `Preview Submission` 后：
- 右侧 `Preview` 区域会生成投稿预览内容
- 预览会显示书名、分类和简介
- 若简介过长，系统会截取前 300 个字符左右显示

### 6.8 提交审核
点击 `Submit for Review` 前，请确认：
- 已登录作者账号
- Title 不为空
- Genres 至少有一个有效分类
- Description 不为空
- File Path 不为空
- 文件在本机真实存在

#### 文件格式要求
作者正式投稿目前支持以下文件格式：
- `.pdf`
- `.txt`
- `.doc`
- `.docx`

如果文件不存在或格式不对，系统会弹出错误提示。

#### 提交成功后结果
提交成功后：
- 系统生成 Submission ID
- 草稿会被清除
- 馆员页待审核列表会刷新
- 作者表单会清空

## 7. Librarian 标签页操作说明
### 7.1 功能概览
馆员页面用于：
- 注册馆员账号
- 登录馆员账号
- 查看待审核投稿
- 预览投稿文件
- 单条批准
- 单条拒绝
- 批量批准
- 批量拒绝

### 7.2 注册馆员账号
在左侧 `Librarian Registration` 区域填写：
- Username
- Full Name
- Password
- Employee ID

点击 `Register Librarian` 完成注册。

### 7.3 登录馆员账号
在左侧 `Librarian Login` 区域填写：
- Username
- Password

点击 `Login Librarian` 后即可进行审核操作。

### 7.4 查看待审核列表
右侧表格会显示待审核投稿，字段包括：
- Submission ID
- Title
- Author
- Genres
- File

选择某一条记录后：
- 系统会自动尝试读取对应文件内容
- 下方 `Submission File Preview` 区域会显示预览结果

### 7.5 刷新列表
点击 `Refresh` 可重新加载当前待审核投稿。

### 7.6 预览投稿文件
操作步骤：
1. 先登录馆员账号
2. 在表格中选中一条投稿
3. 点击 `Preview File`

系统会根据文件内容输出预览：
- 对 `.txt` 或可读文本内容，会显示前若干行
- 对 PDF 或 Word 文档，目前界面不会直接渲染正文，而是给出文件路径和说明

### 7.7 单条批准投稿
操作步骤：
1. 登录馆员账号
2. 选中一条投稿
3. 在 `Comment` 输入可选备注
4. 点击 `Approve Selected`

批准后系统会：
- 将投稿状态变为已批准
- 自动生成图书记录
- 使该图书进入学生/教职员可检索列表
- 刷新待审核列表和图书列表

### 7.8 单条拒绝投稿
操作步骤：
1. 登录馆员账号
2. 选中一条投稿
3. 在 `Comment` 输入可选备注
4. 点击 `Reject Selected`

拒绝后系统会：
- 将投稿状态变为已拒绝
- 从待审核列表中移除
- 保留馆员备注

### 7.9 批量批准与批量拒绝
馆员表支持多选。

操作步骤：
1. 登录馆员账号
2. 在待审核表中选中多条记录
3. 在 `Comment` 中输入统一备注
4. 点击 `Bulk Approve` 或 `Bulk Reject`

若未选中任何记录，系统会提示先选择至少一条投稿。

## 8. 常见业务规则说明
### 8.1 用户名唯一
所有角色共用统一用户仓库，因此用户名全局唯一。
如果某用户名已被任意角色使用，其他角色不能重复注册。

### 8.2 登录角色必须匹配
例如：
- 用学生账号不能按馆员方式登录
- 用作者账号不能按学生方式登录

### 8.3 图书借阅限制
当前借阅规则：
- 每次借阅时长 1 到 14 天
- 单个用户最多同时借阅 5 本书
- 未审核通过的书不能借阅
- 不可借状态的书不能借阅

### 8.4 投稿限制
作者投稿必须满足：
- 标题不能为空
- 分类不能为空
- 描述不能为空
- 文件路径不能为空
- 文件必须真实存在
- 文件格式必须受支持

## 9. 推荐使用顺序
如果你是第一次演示该系统，建议按以下顺序操作：
1. 先启动 JavaFX 图形界面
2. 在 Student / Staff 标签页查看系统默认图书
3. 用 `student1 / Password1!` 登录并借阅可借图书
4. 切换到 Author 标签页，用 `author1 / Password1!` 登录
5. 填写一条新投稿并提交审核
6. 切换到 Librarian 标签页，用 `librarian1 / Password1!` 登录
7. 审核刚提交的投稿
8. 回到 Student / Staff 标签页查看新书是否已进入图书列表

## 10. 常见问题
### 10.1 为什么界面打开后会自己关闭
如果你使用的是 `-SmokeTest` 启动参数，系统会在短时间后自动退出。
正常使用请用：

```powershell
.\Run-Library.ps1 -JavaFX
```

### 10.2 为什么借阅天数不能超过 14 天
这是当前系统业务规则，前端和后端都已限制为最多 14 天。

### 10.3 为什么作者提交文件时报错
请检查：
- 文件路径是否填写正确
- 文件是否真实存在
- 文件格式是否为 `.pdf`、`.txt`、`.doc`、`.docx`

### 10.4 为什么馆员看不到投稿正文
目前系统只会直接预览文本类内容。对于 PDF、DOC、DOCX，界面会显示路径和说明，而不是直接渲染文件正文。
